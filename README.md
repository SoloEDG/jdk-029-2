# 夜航练习室

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本机地址。麦克风需要本机地址或 HTTPS。

## 逐字提示

选中一句歌词后，工作台会出现「逐字提示」面板：

- **自动识别**：参考音（`notes`）多于字数时把相邻音并入同一个字（一个字跨多个音）；字数多于音时把一个音切给紧连的多个字共用提示；行内无参考音则按行时长均匀铺开。自动结果为金色「自动」状态，等待人工确认。
- **标记边界**：在播放位置用旗帜按钮标记某字起点，边界可反复重标，也可用 `−/+` 以 0.03 秒微调；每个字和每个分组都能单独循环试听参考音。
- **整句替换**：粘贴修订后的整句（标点与空格自动忽略），LCS 配对让带历史时点的字随字迁移；无配对的新字给临时时间并标「自动」，迁移后与落点内部重叠的已确认字降级为红色「待复核」，首尾相接不算重叠。
- **分组拖动**：把已对齐分组里的字拖到另一组重复词的前/后放置槽；源组留在原地的已确认字保持原序、原时间、原状态，不会被重排。
- **组中插字**：每个字前都有插入框，可在分组中间插入新字。
- **撤销/重做**：所有编辑压入完整快照历史，撤销后预览与 IndexedDB 存档写入的是同一份快照。
- **旧录音复听**：每条录音保存时结构化克隆当时的逐字提示（`Take.cueSnapshot`），在右侧「练习回顾」复听时显示原提示并随播放高亮当前字。

状态色：绿色「已确认」、金色「自动」、红色「待试听复核」。

## 测试与构建

```sh
npm test        # Node 内置 runner，逐字提示对齐/迁移/历史的纯函数测试
npm run typecheck
npm run build
```

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8029>。可以通过 `NIGHT_SESSION_PORT` 指定其他端口。
